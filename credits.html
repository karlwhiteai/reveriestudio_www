Open-source software

  • MLX, Apple’s machine-learning framework for Apple silicon: MIT.
  • mlx-audio, mflux, ltx-2-mlx and acestep.cpp, which run the models above on Apple silicon: MIT.
  • Hugging Face Hub, Transformers and related libraries: Apache-2.0.
  • PyTorch: BSD-style license.
  • Python: Python Software Foundation License.
  • FFmpeg, for audio and video: LGPL-2.1-or-later. Reverie Studio uses a build without any GPL components, with Apple’s VideoToolbox for video encoding. We will send the FFmpeg source code we build from, and its build configuration, to anyone who asks at hello@reveriestudio.app, for at least three years after we last ship it.
